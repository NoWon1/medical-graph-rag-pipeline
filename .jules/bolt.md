## 2024-05-24 - Vectorized Cosine Similarity & Serialization Bottlenecks
**Learning:** The previous pure Python implementation of cosine similarity caused significant performance bottlenecks in vector reranking loops. Also, applying NumPy vectorization directly returned `np.float64` types, which causes unhandled JSON serialization errors in Streamlit/LangChain UI components. Furthermore, simply replacing inner loop operations with NumPy isn't enough; lists passed into the vectorized loops must be pre-cast to `np.ndarray` prior to the loops to prevent severe implicit conversion overhead.
**Action:** When vectorizing Python loops with NumPy in the graph RAG retrieval system, always pre-cast input lists to `np.ndarray` explicitly before the hot loop begins, and ALWAYS cast scalar NumPy return values explicitly to native `float()` to maintain UI compatibility.
