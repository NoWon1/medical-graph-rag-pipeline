## 2024-07-22 - Avoid Alarming Colors
**Learning:** Using red for standard interactions (like focus rings) creates a false sense of urgency in medical UIs.
**Action:** Use brand colors (e.g., green #2fa36b) for safe, non-critical UI states.
## 2024-08-11 - Add Contextual Guidance Tooltips
**Learning:** Adding contextual guidance tooltips (`help`) and placeholders to interactive components like buttons and text areas improves user intuition without cluttering the screen.
**Action:** Use Streamlit's `help` and `placeholder` attributes on inputs and buttons to provide inline guidance where applicable.
