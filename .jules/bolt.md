## 2024-05-24 - NumPy Array Pre-casting and Float Return in Cosine Similarity
**Learning:** When vectorizing Python loops using NumPy (e.g. for cosine similarity calculations like `np.dot` and `np.linalg.norm`), passing raw Python lists implicitly converts them to `np.ndarray` objects on each function call. If called within hot loops (like MMR reranking or Semantic Image deduplication), this overhead negates the performance benefits. Pre-casting list inputs to `np.ndarray` before entering the loops ensures full vectorization speedups. Additionally, NumPy operations return `np.float64` types which can cause JSON serialization errors in APIs/Streamlit; explicitly wrapping the result in a native `float()` avoids runtime crashes while preserving the vectorized speed.
**Action:** Always pre-cast inputs to NumPy arrays immediately before looping when optimizing vector calculations, and ensure all mathematical scalar results are cast back to native Python types (e.g. `float()`) before returning them to calling scopes.
