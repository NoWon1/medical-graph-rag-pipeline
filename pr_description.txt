💡 What: Added a loading spinner (`st.spinner`) when the application processes uploaded patient reports (`load_report_from_upload`).
🎯 Why: File extraction (especially PDFs) can be computationally heavy. Wrapping this blocking call in a spinner prevents the app from appearing frozen and provides immediate visual feedback to the user that work is in progress.
📸 Before/After: Before, uploading a large PDF caused the UI to silently hang for several seconds. After, uploading a file immediately displays a spinner reading "Processing uploaded report...".
♿ Accessibility: The loading spinner provides critical "Visibility of System Status" for all users, indicating that the system is actively responding to their input.
