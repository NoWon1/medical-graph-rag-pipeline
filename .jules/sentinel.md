## 2025-05-24 - Fix Path Traversal in LLM Image Rendering
**Vulnerability:** The application was vulnerable to Path Traversal / Local File Inclusion (LFI). The `render_message_with_images` function in `cancer_app.py` extracted an image filename directly from LLM-generated output and appended it to `IMAGE_DIR` without sanitizing it or checking if the resulting path resolved outside the intended directory. Because LLM outputs can be influenced by prompt injection from uploaded patient reports or malicious user chat input, an attacker could force the LLM to output a path like `[IMAGE: ../../../etc/passwd]` to read sensitive files on the server.
**Learning:** Never trust LLM outputs when constructing file paths or executing commands. Treat LLM text as untrusted user input, especially in RAG applications where the context includes unverified external documents.
**Prevention:** Always sanitize filenames using `Path(filename).name` to strip directory components. After constructing the full path, strictly enforce that the resolved path is within the intended base directory using `path.is_relative_to(base_dir)` and verify it is a file (`path.is_file()`) before accessing or rendering it.
