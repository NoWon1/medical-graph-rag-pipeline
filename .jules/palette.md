## 2024-07-22 - Avoid Alarming Colors
**Learning:** Using red for standard interactions (like focus rings) creates a false sense of urgency in medical UIs.
**Action:** Use brand colors (e.g., green #2fa36b) for safe, non-critical UI states.

## 2024-08-07 - Add Helpful Guidance to Inputs
**Learning:** Adding placeholders and help tooltips to text inputs and buttons provides immediate contextual guidance, making complex or empty state UIs more intuitive without cluttering the screen.
**Action:** Always consider adding `help` and `placeholder` attributes to form elements (like file uploaders, text areas) and action buttons in Streamlit to improve user onboarding and interaction confidence.
