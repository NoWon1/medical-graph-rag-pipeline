## 2024-05-20 - Adding Tooltips and Placeholders
**Learning:** Adding `help` and `placeholder` attributes to interactive UI components in Streamlit greatly improves user intuition without cluttering the screen.
**Action:** Always include contextual guidance attributes when adding or modifying interactive UI components in Streamlit (e.g., `st.file_uploader`, `st.text_area`, `st.button`).
