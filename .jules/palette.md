## 2024-07-22 - Avoid Alarming Colors
**Learning:** Using red for standard interactions (like focus rings) creates a false sense of urgency in medical UIs.
**Action:** Use brand colors (e.g., green #2fa36b) for safe, non-critical UI states.
## 2024-07-23 - Contextual Guidance in Streamlit
**Learning:** Adding contextual guidance attributes such as `help` tooltips and `placeholder` text to interactive UI components in Streamlit significantly improves user intuition without cluttering the screen.
**Action:** Always include `help` and `placeholder` attributes in components like `st.file_uploader`, `st.text_area`, and `st.button` when appropriate.
