## 2024-07-22 - Avoid Alarming Colors
**Learning:** Using red for standard interactions (like focus rings) creates a false sense of urgency in medical UIs.
**Action:** Use brand colors (e.g., green #2fa36b) for safe, non-critical UI states.
## 2024-08-08 - Adding Tooltips and Placeholders
**Learning:** Adding contextual guidance like tooltips (`help` parameter) and placeholders in Streamlit interactive components (e.g. `st.file_uploader`, `st.text_area`, `st.button`) helps provide necessary guidance to users without cluttering the screen layout.
**Action:** Always add context using `help` and `placeholder` parameters to interactive UI elements for better user experience.
